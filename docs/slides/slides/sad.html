Phần 2

Kiến trúc hệ thống

Vẽ theo code thật trong repo, không theo ý định trên giấy. Bốn mức phóng to dần, mỗi mức trả lời một câu hỏi.

Mức Tên Câu hỏi
1Bối cảnhHệ thống phục vụ ai, nói chuyện với hệ thống nào bên ngoài?
2Khối triển khaiGồm những khối chạy riêng nào: ứng dụng, cơ sở dữ liệu, kho file?
3Thành phầnBên trong API chia thành module nào, module nào phụ thuộc module nào?
4CodeMột module viết thế nào: interface, class, luồng gọi?
Chuyển cảnh. Câu nên nói: tài liệu C4 của nhóm được vẽ ngược từ code đang chạy, nên mọi thứ trên slide sau đều mở repo ra kiểm chứng được. Mức 4 nằm trong tài liệu, không đưa lên slide vì hết giờ.
